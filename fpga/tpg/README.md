# tpg — FPGA test pattern generator (FreeWili 2)

The FW2 FPGA port of the TPG: the same 15 kHz RGB signal and nine patterns as
the OG (`apps/tpg/main`, PIO + DMA) and the ZoomIO port (`fw2/apps/tpg_zio`),
generated by the iCE40UP5K instead of a program on MAIN. FPGA only: a tenth
pattern (a screen of "H" for focus) and a text overlay naming the pattern and
the timing. Built with
[wilifpga](https://github.com/freewili/wilifpga); needs FW2 firmware
v11-preview.1 or newer (`h\f` menu) and power zone 6 on.

## Signal

- 25 MHz design clock (40 ns). Line 1589 clocks = 63.56 us (15.73 kHz),
  field 262 lines (60.05 Hz; 59.94 Hz would need 262.5), non-interlaced, RS-170 equalizing and serrated vsync pulses.
- Every constant is `apps/tpg/main/video_timing.h` rounded half up to 40 ns:
  HSYNC 4.72 us, back porch 4.68 us, active 52.64 us, front porch 1.52 us,
  EQ pulse 2.32 us.
- x = 0 is the hsync leading edge and the vertical-interval pulses start on
  it (RS-170). The OG starts lines at the front porch, so its vertical
  interval sits 1.52 us off the hsync grid; this design does not copy that.
- All ten outputs are registered and change on the same clock edge.

## Pins

Same header pins as the OG and ZoomIO builds, so the same ladder board and
cable work. MSB first per channel (bit 2 on 120 ohm, bit 1 on 240, bit 0 on 470).

| Signal | GPIO | Header pin | wilifpga signal |
|---|---|---|---|
| B2 / B1 / B0 | 8 / 9 / 10 | 9 / 5 / 7 | uart_tx / uart_rx / uart_cts |
| G2 / G1 / G0 | 11 / 12 / 13 | 11 / 12 / 1 | uart_rts / spi_miso / spi_cs |
| R2 / R1 / R0 | 14 / 15 / 26 | 15 / 13 / 14 | spi_sclk / spi_mosi / gpio26 |
| CSYNC (active low) | 27 | 3 | gpio27 |

Caveats from wilifpga:
- `uart_rx` (GPIO9, B1) as `FPGA_OUT` "did not drive the header pin in
  testing". On our FW2 (firmware v11-preview.1) it does drive: checked
  2026-11-05 on a CRT, where the blue column's level-2 band (B1 only) in the
  RGB gradient is lit. The gradients step through levels 0-7 in eight 30-line
  bands, so each bit of each channel also gets a band to itself (levels 1, 2
  and 4); a dead pin shows as a black band.
- GPIO26 (R0) and GPIO27 (CSYNC) go high for up to about 250 ms during every
  load. Harmless here: a brief faint red and no sync.

## Registers

| Addr | R/W | Meaning |
|---|---|---|
| 0x10 | rw | Pattern, `tpg_pattern_id_t` order (0 color bars ... 8 solid green), then 9 focus ("H" screen). Others show black. Applied at the next field start. Resets to 0. |
| 0x11 | ro | Field counter, +1 per field, wraps at 256. |
| 0x12 | ro | Pattern count (10). |
| 0x13 | rw | Control. Bit 0: text overlay. Applied at the next field start. Resets to 1. |

## Text

- 40 x 30 cells of 8 x 8 pixels, a pixel 4 clocks (160 ns) wide, so 1280 of
  the 1316 active clocks (centered) and lines 0-239. Glyphs are the FW2 UI's
  5 x 7 font (`wilibsp/bsp/display/font5x7.c`, MIT, see `wilibsp/LICENSE`)
  in pixel columns 1-5 and rows 0-6 of a cell.
- Overlay: a black box over cell rows 24-25 (lines 189-209, columns 10-28
  plus 3 pixels each side) with the pattern name and `15.73 KHZ  60.05 HZ`,
  white, centered.
- Focus (pattern 9): an "H" in every cell, white on black.
- The text lives in block RAM: `tpg_text_rom.v` (label and font ROMs) and
  `tb/tpg_text_model.vh` (the testbench's copy of the raw font and strings)
  are generated by `gen_text_rom.py` from the font and
  `apps/tpg/common/tpg_patterns.c`. Rerun it after changing a pattern name,
  the timing line or the font, and keep `TXT_BOX_*` in `user_core.v` in step
  with the columns it prints (the testbench fails if they differ).

## Build, simulate, load

The wilifpga tools only look in `wilifpga/designs/`, so link this folder in
once (Windows, no admin needed):

```powershell
New-Item -ItemType Junction -Path wilifpga\designs\tpg -Target fpga\tpg
Add-Content wilifpga\.git\info\exclude "/designs/tpg"
```

Then, from `wilifpga/`:

```sh
tools/fwfpga toolchain install   # once, ~1 GB pinned oss-cad-suite
tools/fwfpga lint tpg
tools/fwfpga sim tpg             # black-box check of every clock of a field, all patterns
tools/fwfpga build tpg           # -> build/designs/tpg/tpg.fwfpga
tools/fwfpga install tpg
tools/fwfpga load tpg            # color bars right away
tools/fwfpga reg w 0x10 0x04     # crosshatch + dots
tools/fwfpga reg r 0x11          # twice: should advance ~60 per second
tools/fwfpga restore
```

## Display app

`fw2/apps/tpg_fpga` embeds this design at build time (it runs `fwfpga build
tpg`, so the toolchain is needed) and is installed as `/apps/Misc/tpg_fpga.uf2`.
It writes `/fpga/tpg.fwfpga` when that file is missing or from another build,
loads it, and steps patterns with GREEN / YELLOW; BLUE turns the text overlay
on and off; RED restores the stock gateware or reloads TPG. Bump `version` in
`design.toml` with every gateware change: the app keeps a running design whose
id and version match, so an unchanged version leaves the old bitstream loaded. From `wilibsp/`:

```sh
python tools/fw.py install-app --folder Misc --port COM14 ../build-fw2/apps/tpg_fpga/tpg_fpga.uf2
python tools/fw.py run-app --port COM14 Misc/tpg_fpga.uf2
```

Firmware equivalents: `h\f\l`, `h\f\w 10 <nn>` (hex), `h\f\r 11 1`, `h\f\t`;
OneWili commands 694-702. The **Default FPGA** setting (`h\s\e\c`) can boot
the design, giving color bars at power-up with no app.
